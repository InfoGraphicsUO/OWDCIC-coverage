An interactive web map showing wildfire cameras, viewshed coverage, and fire activity across Oregon and Washington.
[Click here to view](https://infographicsuo.github.io/OWDCIC-coverage)

[Report issues, request features, or assign tasks in the issue tracker](https://github.com/InfoGraphicsUO/OWDCIC-coverage/issues)

---
You can download shapefiles of every camera viewshed, the same polygons the map shows. Each zip has one layer per camera provider, the combined coverage, camera locations, and a README describing the fields. 

The latest released shapefiles can be found below. Your download will start immediately.

- [Oregon Download](https://github.com/InfoGraphicsUO/OWDCIC-coverage/releases/latest/download/owdcic-viewsheds-oregon.zip)
- [Washington Download](https://github.com/InfoGraphicsUO/OWDCIC-coverage/releases/latest/download/owdcic-viewsheds-washington.zip)
- [Oregon and Washington Combined Download](https://github.com/InfoGraphicsUO/OWDCIC-coverage/releases/latest/download/owdcic-viewsheds-or-wa.zip)

Older versions are on the [releases page](https://github.com/InfoGraphicsUO/OWDCIC-coverage/releases).
